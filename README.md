# ზეთების ფასების საიტი (GitHub Pages)

ეს რეპოზიტორია არის ფასების „სერვერი“:

- `data/snapshots/` — აქ თავისით იტვირთება ყოველდღიური ფასების ფაილები შენი კომპიუტერიდან.
- `scripts/build.py` — GitHub-ზე ეშვება, აწყობს ფასების ისტორიას და ფასის ცვლილებისას email-ს აგზავნის.
- `index.html` — საიტი: შედარება ჩვენს ფასებთან, Tegeta-ს ყველა ფასი, ცვლილებები.
- `my_products.csv` — ჩვენი პროდუქტები და ფასები. პირდაპირ GitHub-ზე შეგიძლია შეცვალო.

## ჩვენი პროდუქტების რედაქტირება

GitHub-ზე გახსენი `my_products.csv` → ფანქრის ხატულა (Edit) → შეცვალე → **Commit changes**.

```
product,my_price,tegeta_url
Mobil Super 3000 5W-40 4L,115,
```

- `product` — სახელი. ჩაწერე ბრენდი, სიბლანტე (5W-40) და მოცულობა (4L), რომ Tegeta-ს პროდუქტი ავტომატურად მოიძებნოს.
- `my_price` — ჩვენი ფასი ლარებში.
- `tegeta_url` — ცარიელი დატოვე. თუ ავტომატურად არასწორი პროდუქტი დაწყვილდა, აქ ჩასვი Tegeta-ს სწორი პროდუქტის ლინკი.
